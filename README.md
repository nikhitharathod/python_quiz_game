# Python Quiz Game 🎮

## Overview
Python Quiz Game is a simple command-line application developed using Python. The program asks users quiz questions, checks their answers, and calculates the final score. It is designed as a beginner-friendly project to practice Python programming and logical problem-solving.

## Features
- Interactive quiz in the terminal
- Multiple questions support
- Automatic score calculation
- Simple and user-friendly interface
- Easy to modify and expand

## Technologies Used
- Python 3
- Command Line Interface


## Learning Objectives
This project helps in understanding:
- Python basics
- Conditional statements
- Loops
- Functions
- User input handling
- Simple game logic

- Add timer for questions
- Add difficulty levels
- Save high scores
- Add graphical interface
